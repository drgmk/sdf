Welcome to sdb

This is the second version of sdb. Underlying this website is a target and photometry database (sdb), and software that fits exported photometry with stellar models (sdf). The main changes from the first version are that the sdb database is now based on sqlite, sdb and sdf can now handle multiple systems, and the user interface is much more capable.

Typical users will only see SEDs and samples. An account is needed to access and create private samples, and to import new targets. Users with admin privileges can do more, e.g. configure targets.

There are no private data here, so all individual SED pages are public. Samples, which are simply groupings of targets, can be private.
